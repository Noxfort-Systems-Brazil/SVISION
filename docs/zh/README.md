# SVISION Core — 文档门户 (简体中文)

> **语言 / Language:** [English (完整版)](../en/README.md) · [Português (完整版)](../pt-br/README.md) · [Español](../es/README.md) · [Français](../fr/README.md) · [Русский](../ru/README.md) · **中文**

**SVISION Core v1.2.0** 是一款实时分布式交通流分析引擎，融合了 **Tauri v2 / React 18** 桌面工作站、基于 **Python 3.12（TensorRT INT8 与 F.E.N.I.X. 容错监管器）** 的 GPU 推理守护进程，以及 **Go 语言零积压网络转发器（`bin/synapse-dispatcher`）**。
